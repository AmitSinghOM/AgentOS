## v0.10.0-ui — The log, made visible

Phase 9 close-out. An operator UI served by the API itself at `/ui`, shipped inside the wheel and the image. Every screen is a consumer of the event log: the browser never folds events, never decides authorization, never holds a token anywhere but the tab.

### What ships

- **Approvals inbox** (#58). `GET /me` shows who the log will name before any button is enabled; bearer token in `sessionStorage` only (no localStorage, no cookie, no URL); decision bodies are the API's own; 401/403/409/422 rendered verbatim; asserted mode labelled **Unverified**. Same origin (`agentos/api/ui.py`): only static files under `/ui` are exempt from auth, and a test enumerates the routes to prove it.
- **Live run graph** (#59). `/ui/runs/<id>` draws the DAG from `GET /workflows/{name}` with longest-path layering (no graph library); node states come from the server's folded run; the stream is read with `fetch` + an SSE parser (`EventSource` cannot send `Authorization`), every frame scheduling one refetch; reconnects with `Last-Event-ID`; a pinned-version mismatch is stated (C3). Landing page over the new `GET /runs`.
- **Timeline with time travel** (#60). `GET /runs/{id}?at=k` folds the log prefix on the server — the same fold the golden corpus pins as equal to the full fold at every cut point. Scrub or click a seq; the graph and cost panel show the run as it was right after it.
- **Cost + latency panel** (#60). Per node: attempts, first start, finish, duration, cost; run cost and wall time. Cost from the fold; timestamps from the events (the one display derivation, stated).
- **In the wheel and image** (#59). `scripts/bundle_ui.py` copies the Vite build into `agentos/_ui` before `python -m build`; `pip install agentos-durable` serves `/ui` with no Node at runtime; the release smoke refuses a wheel without it.

### Install

```bash
pip install "agentos-durable[providerkit]" agentos-provider-openai-compat
uvicorn agentos.api.main:app && open http://localhost:8000/ui/
docker run --rm -p 8000:8000 ghcr.io/amitsinghom/agentos:0.10.0
```

### Events

No new event types. Two new read routes (`GET /runs`, `GET /workflows/{name}`), one new query parameter (`?at=`), one new endpoint (`GET /me`). Golden `v0.10.0.json` recorded; all ten golden logs fold and `fold_from == fold` at every cut point.

### Numbers

473 → 496 Python tests; 34 UI tests (Vitest + Testing Library; SSE parser at every chunk boundary, layout, node-state precedence, inbox, graph over a scripted stream, time travel with a hand-written `?at=` oracle). Defects the review caught in the author's own work before merge: a rejected token re-sent on every reload; an unbounded stream reconnect on hard errors; the previous seq's state shown under the new seq's banner.

### Not in this release, on purpose

A UI kit (none while the pages are tables and SVG); a CSP header for `/ui`; a store index behind `GET /runs` / `GET /approvals`; versioned workflow definitions so an old run's graph can be drawn from the definition it pinned; Playwright (no browser on the build host — mount tests run against the real bundle in CI instead).
