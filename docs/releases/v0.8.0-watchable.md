## Phase 7 — Streaming + inner harness

A pilot evaluator can watch a run live from any process, and can run the agent SDK they already use as a step governed by AgentOS's gate, cost meter and log. Scoped by the [landscape check of 2026-09-17](../../ROADMAP.md#landscape-check--2026-09-17-after-v070-complete): streaming was the one disqualifying gap for a pilot; the inner harness is the move that lets the differentiators (declared effects, cost ceilings, hash chain) apply to a loop people already run.

### What ships
- **`GET /runs/{id}/stream`** (#44, `agentos/api/stream.py`) — Server-Sent Events over the run's log. It is a *consumer of the log*: the API polls `read_events(after_seq)`, so it works from any process (verified through separate API and worker processes with the quickstart's `curl -N`) and needs no in-memory subscription map. `id` = `seq`; `Last-Event-ID` or `?after=` resumes. Closes on the terminal event, including when the resume point is already at or past it (a client resuming at the terminal seq would otherwise have waited out the full bound — caught in test). Keep-alive comments while idle. `data` is byte-identical to `/events`, non-ASCII included. Env: `AGENTOS_STREAM_POLL_SECONDS` (0.25), `AGENTOS_STREAM_KEEPALIVE_SECONDS` (15), `AGENTOS_STREAM_MAX_SECONDS` (3600). Event-level, not token-level.
- **`agentos-provider-openai-agents`** (#45, `providers/openai-agents/`) — runs an OpenAI Agents SDK agent as one AgentOS step. The SDK owns the loop; AgentOS owns the gate, cost and log. Tools are operator-registered Python (`agentos.openai_agents_tools` entry point), each with an effect class; the model is offered only tools whose class the AgentOS agent *declared*, the rest are withheld and listed. A step declaring `spend` is suspended before dispatch by the existing tier-2 gate — proven through the core: `run.started, approval.requested, run.suspended`, no `step.started`, zero model calls. Each step runs on its own `asyncio.run` loop and closes its `AsyncOpenAI` client in `finally` (review finding: `Runner.run_sync` leaves the thread loop and its pool open). SDK `needs_approval` interruptions raise; nothing auto-approves. Tested against the SDK's `ScriptedModel` with no network; live against Ollama. The core is forbidden from importing `agents`.
- **Boundary echo fix** (#46) — `DATA_BOUNDARY` is appended after the operator's system prompt, so it is the last instruction a model reads; `qwen2.5:0.5b` at temperature 0 returned it as its "poem" for 7 of 20 quickstart topics, including the default "event logs". Framed as "Note on the input format: …" the echo drops to 1 of 20. Measured by `scripts/probe_boundary_echo.py`; the frame is pinned by `tests/test_trust_boundary.py`; cassettes for both wire formats re-recorded live; verified through API + worker on all three LLM executors.
- **Plan** (#43) — `ROADMAP.md` records the three-layer landscape framing and the layer-3 table; Phase 7 rescoped to these two items, UI moved to Phase 8.
