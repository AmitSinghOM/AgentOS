## Phase 4 — Providers + developer experience

A real model in five minutes with no API key, from a package a stranger would adopt for a pilot. Providers are **plugins** (docs/DEVELOPMENT_STRUCTURE.md §2.2): separate MIT distributions the core never imports; two wire formats shipped with zero core changes between them.

### What ships
- **`agentos-provider-openai-compat`** (`providers/openai-compat/`): any OpenAI-compatible chat-completions server over plain httpx — Ollama zero-config default (no key), vLLM, LM Studio, OpenRouter, OpenAI. No vendor SDK.
- **`agentos-provider-anthropic`** (`providers/anthropic/`): the Anthropic Messages API — Anthropic, and Ollama's `/v1/messages`. Different request shape, auth header, error envelope (incl. 529); same agent-config vocabulary. An agent moves between providers by changing `executor`.
- **`agentos.providerkit`** (extra `agentos[providerkit]`, forbidden to the core, in the adapter-independence contract): cassette transport, pricing table, error vocabulary, `{run.x}` prompt templates, `config_from_env(prefix)`, conformance scenarios. A third provider is one executor module.
- **Entry-point discovery** (`agentos.executors`) in the composition roots; broken plugin skipped with a warning; `Agent.executor` routes by name; missing executor → run fails with the install hint and what *is* registered. `GET /executors` shows each plugin's `describe()` + `health()`.
- **A3 aliases + `executor.substituted`**: `chat.fast` resolved by the plugin before dispatch; a changed resolution for the same agent mid-run is recorded before `step.started`, principal `system:<executor>`; completed steps never re-run.
- **A6 closed**: metered `Cost` from real usage (input/output/requests, plus `cached_input_tokens` where the server reports it), Decimal amounts, pricing table stored as a blob at startup → `GET /blobs/{sha256}`.
- **A10 cassettes**: dependency-free record/replay; committed cassettes recorded from a live Ollama (`source` in each file); nightly `provider-live` job re-records both providers on a runner and replays — first dispatched run green.
- **Run inputs**: `POST /workflows/{name}/runs {"inputs": …}` stored by hash, visible to every step as `{run.…}`; workflows without inputs unchanged.
- **DX**: `docs/quickstart-llm.md` executed by `tests/test_quickstart_llm.py` (both providers) and run live end to end with separate API + worker; `scripts/quickstart_llm.py [--executor anthropic]`; actionable error messages verified live (server down, model missing); typed config with documented env defaults; provider READMEs; `examples/{poet,critic}_agent.json`, `haiku_workflow.json`.
- **Events** (additive; `schema_version` stays 1): `executor.substituted`; `run.started.inputs_ref`. `tests/golden/v0.5.0.json` recorded with both; v0.2.0–v0.4.0 golden logs still fold.
