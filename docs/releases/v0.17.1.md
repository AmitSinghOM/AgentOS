## v0.17.1 — PyPI matrix fix: all six distributions on PyPI

A patch release so that `agentos-provider-acp` reaches PyPI. The `v0.17.0` tag's `publish.yml`
run built, attested and attached six wheels to the GitHub release, but the `pypi` job's matrix
named only five of them — `dagentos` and four providers landed on PyPI (each through its own
pending Trusted Publisher, approved one at a time) and the ACP provider was never uploaded.
`docs/RELEASING.md` keeps one version for the core and every provider, so the fix ships as a new
tag and every distribution moves to `0.17.1`. Nothing in the engine, API, UI or event log
changed.

### What changes

- **`agentos_provider_acp` in the PyPI matrix** (#132). `publish.yml`'s `pypi` job lists all six
  distributions. A packaging lock,
  `tests/test_packaging.py::test_pypi_matrix_lists_every_distribution_the_build_job_builds`,
  derives the expected set from `providers/*/pyproject.toml` and fails on the old five-entry
  matrix, so a seventh distribution cannot be left behind the same way.
- **jsdom 30.1.2 → 31.0.1** (#131), a UI devDependency used only by `vitest`; nothing in
  `ui/dist` ships it. jsdom 31's own `engines` floor is Node `^22.22.2 || ^24.15.0 || >=26`
  and it moves `undici` to `^8.12.3` (lockfile resolves 8.12.4). CI's `setup-node` is `22`.
- Version `0.17.0` → `0.17.1` at every site `docs/RELEASING.md` names: `pyproject.toml`, the five
  `providers/*/pyproject.toml`, `dagentos/api/main.py` (`FastAPI(version=)`), and
  `ui/package.json` + `ui/package-lock.json`.

### Install

```bash
pip install "dagentos[providerkit]" agentos-provider-openai-compat
uvicorn dagentos.api.main:app && open http://localhost:8000/ui/
docker run --rm -p 127.0.0.1:8000:8000 ghcr.io/amitsinghom/agentos:0.17.1
```

All six distributions — `dagentos` and `agentos-provider-{openai-compat,anthropic,openai-agents,pydantic-ai,acp}`
— publish from this tag's run. Every wheel and the image carry Sigstore-signed provenance;
`docs/RELEASING.md` shows how to verify.

### Events and API

No new event types, routes, settings, port methods or migrations. Golden logs unchanged.

### Numbers

Measured in a Python 3.13.12 venv with every provider installed (`pytest --collect-only -q`):
`tests/` 625 → 626 collected (617 → 618 outside `tests/chaos`; the one addition is the packaging
lock above); provider suites 116, unchanged (acp 43, anthropic 16, openai-agents 14,
openai-compat 18, pydantic-ai 25). `docs/FAIL_MODES.md` 80 rows, unchanged. UI tests 99,
unchanged. UI bundle unchanged (no source change).
