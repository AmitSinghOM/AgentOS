## Phase 3 — Human-in-the-Loop + Observability

Production-shaped: pausable, traceable, costed. Approval is a **run state** the engine knows about, not a library pattern; telemetry is **derived from the event log**, not scattered through the engine.

### What ships
- **Approval as a run state (C7).** The declare-then-do gate has three tiers by declared effect class: allowed → runs; `approval_required_for` (default write_external, spend, send_message, execute_code) → `approval.requested` + `run.suspended` **before dispatch** (no `step.started`, no attempt consumed; ungated siblings run and are recorded first); neither → refused. Lease released, run leaves the queue, sweep skips it, `advance()` is a no-op.
- **Principal-gated decisions (A2).** `approve`/`reject` require a `Principal` (422 without); `spend`/`write_external` and cost approvals require a human unless `Budget.allow_agent_approval` (403). The approved step runs exactly once, after the grant (`step.started.seq > approval.granted.seq`, asserted), tagged with its `approval_id`. Reject → dead-letter naming the decider → run failed; retry reopens and re-asks. `approval_timeout_seconds` → rejected by the `system` principal on the worker's sweep. `GET /approvals` inbox.
- **Cost-ceiling suspension (A6, DESIGN §8).** Exceeding `max_run_cost` records the tripping step, then suspends with a `kind=cost` approval; granting raises the ceiling to `total + max_run_cost` (recorded in the log as `run.cost_ceiling`); trips again at the raised ceiling; rejection fails the run without a dead-letter.
- **OpenTelemetry (A9).** `Observer` port; one span per run and per step attempt derived from events, timestamps from `occurred_at`; `gen_ai.*` attributes pinned and checked against the installed semconv; `agentos.*` for the rest; approvals/suspension/dead-letters as span events with the principal. Core imports no SDK (contract + fresh-interpreter test).
- **Prometheus (C8).** `GET /metrics`: run/step duration histograms, outcomes, retries, dead-letters by effect class, cost, metered units by agent, approvals requested/decided/wait, `runs_suspended` gauge, `queue_depth` (scrape-time collector). Low-cardinality labels only.
- **Replay equivalence.** `agentos.observability.replay(store, run_ids, observers)`; live vs replayed spans and metrics are identical (tested).
- **Compose:** Jaeger 2.9, Prometheus 3.6, Grafana 12.2 with provisioned datasource + 10-panel dashboard; CI checks all three come up. New `agentos[observability]` extra.
- **Events** (additive; `schema_version` stays 1): `approval.requested` (+ `kind`, `cost_at_request`, `proposed_ceiling`), `run.suspended`, `approval.granted`, `approval.rejected`. v0.2.0 and v0.3.0 golden logs fold under this release; `tests/golden/v0.4.0.json` recorded.
