## Phase 2 — DAG Orchestration

Real multi-agent workflows: parallel branches, retries that cannot corrupt the record, poison steps dead-lettered with the cause, operator cancel/pause, and agents versioned and pinned per run. The roadmap demo — 1 → [2,3,4] → 5 with one branch failing and retrying — is `tests/test_scheduler.py`.

### What ships
- **Wave scheduler.** Nodes whose dependencies are complete run concurrently, bounded by `max_parallelism`. One serialized appender per `advance()`; closed on return so a straggler thread can never write after a terminal event. Every step of a wave is settled before the run's fate is decided: a completed sibling of a dead-lettered or cancelled wave-mate is always recorded.
- **The governor.** `Executor.execute(StepRequest, progress) -> StepResult`. Gate (declared effects vs budget, refused *before* dispatch) → dispatch → verify (reported effects ⊆ declared; metered cost and wall time within budget) → record (`step.completed` with effects, Decimal cost + pricing-snapshot hash, provenance). `progress()` renews the lease, rate-limits `step.progress`, and is the cooperative cancellation token.
- **Retries with backoff.** `RetryPolicy` per node; `step.failed(terminal=False, retry_at)`; the worker re-enqueues with `delay_seconds` instead of sleeping; exponential and capped. Last attempt → `step.dead_lettered("failed after N attempt(s): …")` → `run.failed`. One dead-letter path for poison steps and governor refusals.
- **Human retry.** `POST /runs/{id}/steps/{step}/retry` records the `Principal`, reopens the run, and attempt numbering continues; healthy steps replay from the log.
- **Cancel / pause / resume.** Persisted requests finalized at the worker's next boundary, or immediately under a lease when the run is idle/paused. Control requests are the only foreign appends the engine's log adopts on conflict. Heartbeating steps are interrupted; silent steps are recorded; pause finishes the wave and leaves the queue. A client disconnect cannot change run state.
- **Agent versioning.** Immutable per `(name, version)` in every store (409 on a changed body); runs pin every agent at start and resolve against the pin on each attempt; `step.started.agent_version`; `GET /agents/{name}?version=N`.
- **Events** (all additive; `schema_version` stays 1): `step.progress`, `step.dead_lettered`, `step.retry_requested`, `step.cancelled`, `run.cancel_requested`, `run.cancelled`, `run.pause_requested`, `run.paused`, `run.resumed`; fields on `step.completed`, `step.failed`, `step.started`, `run.started`. The v0.2.0 golden log folds under this release; `tests/golden/v0.3.0.json` recorded.
- **CI:** the Toxiproxy race is parametrized so the fence and the heartbeat are proven independently.
