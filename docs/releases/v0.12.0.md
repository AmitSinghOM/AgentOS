## v0.12.0 — The log, made legible

The operator UI's detailing release (#66), on top of the v0.11.1 package-review fixes. Still no UI kit, and the browser still derives no state: every value on screen is the server's fold or a field of the log. What changed is how much an operator can read at a glance.

### What ships

- **Times you can read.** Local `HH:MM:SS.mmm` everywhere with the ISO instant in a title; `requested 43 min ago` in the inbox and `started 2 h ago` in the runs list. Every formatter degrades to the raw value when it cannot parse — never `Invalid Date` (unit-tested, `ui/src/fmt.ts`).
- **Gap column.** The timeline shows the signed interval from the previous event (`+37 ms`, `+2.30 s`) — the first thing an operator reads when a step is slow.
- **One colour language.** Design tokens for run states (completed / running / awaiting / failed / cancelled) and for event families (run / step / approval / governance / integrity / executor), light and dark; the same colour means the same thing on the graph, the tables, the timeline dot and the ticker.
- **Graph.** Per-node status stripe, hover emphasis, and a legend of the states present in *this* run.
- **Chips with titles.** Run header: status pill, live indicator, version, events, cost, `sealed ≤ n`, `policy <12 hex>` (full hash on hover), started time. Inbox: effect classes (`spend`, `write_external`, … in the warn colour). Runs list: mono ids, version chip. Masthead: the auth mode from `GET /me`.
- **Tables.** Right-aligned tabular numerals, sticky headers, hover rows; an empty state that says how to start a run.
- **Accessibility.** `:focus-visible` outlines, `prefers-reduced-motion` disables the pulse and blink, `<time dateTime>` on every timestamp, run graph exposed as a group (from v0.11.1).

### Install

```bash
pip install "dagentos[providerkit]" agentos-provider-openai-compat
uvicorn dagentos.api.main:app && open http://localhost:8000/ui/
docker run --rm -p 8000:8000 ghcr.io/amitsinghom/agentos:0.12.0
```

### Events

No new event types, routes or parameters. Golden logs unchanged.

### Numbers

510 Python tests; UI tests 40 → 45. The rebuilt bundle renders every screen under the v0.11.1 Content-Security-Policy with zero violations in headless Chrome.

### Not in this release

A UI kit (still deliberately none); light-scheme screenshot verification (the tokens exist, the host's Chrome ignored the forced-scheme flag); the store index behind `GET /runs` and `GET /approvals`.
