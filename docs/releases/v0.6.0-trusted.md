## Phase 5 — Trust boundary + polish

The last structural landscape con closed, and the README shows the system running.

### What ships
- **C12 trust boundary** (#12, `docs/TRUST_BOUNDARY.md`), three boundaries each tested:
  - *Control payloads carry a decision, never work.* approve/reject/cancel/pause/resume/retry bodies are `principal` + `reason` and nothing else (`extra="forbid"`). A payload smuggling `tool_call`, `output`, `next_step` or `inputs` is 422 before the engine, logged with the field names; no event, no step, run unchanged. The issue's acceptance test, over four smuggled shapes and all six endpoints.
  - *Replayed events are tamper-evident.* Every appended event carries `prev_hash`/`hash` (SHA-256 of its canonical record, incl. `seq` and `prev_hash`), computed in the core before the store sees it. `fold()` verifies the chain: edit / insert / remove → `FoldError("log integrity violation: seq N …")`, `GET /runs/{id}` → 500 with that detail, `GET /runs/{id}/integrity`. Pre-v0.6.0 logs fold as before and cannot be extended unhashed. Contract test: the chain survives every store adapter's serialization. A chain, not a signature — said so in the note.
  - *Model inputs are data, never prompt.* Interpolated values wrapped as `<input name="…">…</input>` (early close escaped), `DATA_BOUNDARY` in every system prompt on both providers; structural test that a step output cannot choose the next step, executor or effect class.
- **Observability across processes.** Found by taking the screenshots: the worker's observers never saw `run.started`, so Prometheus labelled everything `workflow="unknown"` and Jaeger got orphan step spans. Now trace/run-span ids derive from the run id, observers resolve run facts from the store (`store_resolver`), run-level happenings are child spans, approval wait resolves across processes, and the worker serves `/metrics` on `:8001`. Replay equivalence still holds.
- **README screenshots** from a real two-process run against Ollama: a Jaeger trace suspended for a human's `spend` approval and resumed; the Grafana dashboard with every panel populated. `scripts/demo_traffic.py` reproduces the traffic.
- **Events** (additive; `schema_version` stays 1): envelope gains `prev_hash`, `hash`. `tests/golden/v0.6.0.json` recorded fully chained (13/13 verified); v0.2.0–v0.5.0 golden logs still fold.
