## v0.11.1 — Package review fixes

A patch release carrying the five-seat package review of v0.11.0 (#64): Staff / Product / Frontend / Security / CTO seats, the code-reviewer skill's pipeline, and cqa before and after. Seven findings accepted and fixed, each locked by a test; nine candidates dismissed with written reasons in the PR.

### What changes

- **Security headers on `/ui`** (A1). Every response under `/ui` — the app shell, root files and the assets mount — now carries `Content-Security-Policy: default-src 'self'; … connect-src 'self'; frame-ancestors 'none'; object-src 'none'; base-uri 'none'`, `X-Content-Type-Options: nosniff` and `Referrer-Policy: no-referrer`. API routes are unchanged. The bundle has no inline script or style, so `'self'` is sufficient; verified in headless Chrome with zero violations. Closes the "CSP header for /ui" leftover from v0.10.0.
- **Time-travel scrubber debounced** (A2). A drag across the timeline is now one `GET /runs/{id}?at=k` (an O(k) server fold) when the thumb rests, not one per slider step; the shown seq still follows the thumb instantly. Test proves a six-step drag went from 6 requests to 1.
- **Run graph reachable by assistive tech** (A3). The SVG is `role="group"`, not `role="img"`, whose children-presentational semantics hid every node's `<id>: <state>` label.
- **Malformed run id in the URL** (A4) falls back to the runs list instead of throwing during render (blank page).
- **API not answering** (A5). A network error or 5xx on `/me` shows "The API is not answering … Retry"; the sign-in form is the answer to a 401 only.
- Recent-decisions list keyed by a stable id (A6); three comments that still named the pre-rename `agentos` import/install (A7).
