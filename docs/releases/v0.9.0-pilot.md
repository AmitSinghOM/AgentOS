## v0.9.0-pilot — A human said yes; prove it

Phase 8 close-out. Every guarantee AgentOS makes about *who* decided something is now enforced at the boundary, bounded by an operator, verifiable after the fact, and the software is installable by a stranger with provenance. This is the first release built for someone who is not the author to run behind a controlled edge.

### What ships

- **Authenticated principals** (#52). `AGENTOS_AUTH=bearer` resolves `Authorization: Bearer` to a `Principal` through a file of SHA-256 hashes; a body `principal` is rejected 422, not replaced; an `agent`-kind token can neither approve `spend` nor define workflows; the recorded principal carries `attestation = token:sha256:<12 hex>`. Middleware, so a route added later is protected by default. Default `asserted` keeps the quick start zero-config and warns once.
- **Operator policy ceiling** (#54). `AGENTOS_POLICY` intersects every workflow budget before the gate, the settle checks and the approve path see it — tightest wins, the gate itself unchanged. `governance.policy_applied` records which ceiling governed each run. `GET /policy`.
- **Sealed chains** (#55). `AGENTOS_SIGNING_KEYS` seals every idle/terminal event in the same batch with an HMAC under a key the database host does not hold. Rewrite-and-rechain is caught; deleted seals show as `unsigned_tail`; truncation after the last seal is reported as the one thing no in-log scheme catches.
- **`agentos` CLI** (#55): `verify` (exit 1 on any chain or seal failure), `doctor` (store, migrations, executors, auth/policy/signing, every run folds and verifies), `policy explain <workflow>`.
- **`docs/FAIL_MODES.md`** (#53): 61 chokepoints, each with a direction and the test that pins it; drift-tested.
- **Publishing with provenance** (#56). Distribution **`agentos-durable`** (`agentos` on PyPI belongs to agentos.org — same import name; do not install both). Wheels with Sigstore-signed SLSA provenance, a multi-arch image built from those wheels, `SHA256SUMS`, every action SHA-pinned. PyPI upload via Trusted Publishing behind an explicit repository switch (`docs/RELEASING.md`).

### Install

```bash
pip install "agentos-durable[providerkit]" agentos-provider-openai-compat
docker run --rm -p 8000:8000 ghcr.io/amitsinghom/agentos:0.9.0
gh attestation verify agentos_durable-0.9.0-py3-none-any.whl --owner AmitSinghOM
```

### Events

Two new event types, additive; `schema_version` stays 1: `governance.policy_applied`, `integrity.sealed`. Golden `v0.9.0.json` carries both (sealed with a fixture key the test verifies against); all nine golden logs fold and `fold_from == fold` at every cut point.

### Numbers

327 → 473 tests. Each slice: four-seat debate, code-reviewer skill, serialized security pass, cqa upgrade-not-degrade (Design 9.1 → 9.36). Defects the process caught in the author's own work before merge: served OpenAPI declared no security scheme (#52); the gate asked a human to approve a step the policy could never run (#54); a seal was not bound to the sealed event's run id (#55); hatch could not select files for a distribution whose name differs from the import package, the sdist shipped the whole tree, and the image smoke used a mixed-case registry path (#56, found by the dry run).

### Not in this release, on purpose

PyPI Trusted Publisher configuration (Amit's account); import-package rename away from `agentos`; Ed25519 signer; external anchor for post-seal truncation; `agentos snapshot`; triggers, Slack adapter, redaction, sensitive paths, sandbox (Phase 8 ⏭ list, in that order).
